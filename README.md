
# Speed Car Run User Manual
## Introduction: 
Welcome to Speed Car Run! This user manual will guide you through the thrilling world of high-speed racing on your Android mobile device. Get ready to experience adrenaline-pumping challenges as you race against time and master the tracks. This manual will help you get started and become a champion racer.
## System Requirements:
-	Android Mobile Device
-	Unity Editor version 2022.3.7f1 LTS
-	Visual Studio Code (or any code editor of your choice)
## Installation:
1.	Ensure that your Android device meets the minimum requirements.
2.	Download the game's source code from the provided GitHub repository: https://github.com/khushalGrover/Speed-Car-Run/tree/main_v2
3.	Extract the downloaded files to your computer.
4.	Open Unity Editor (version 2022.3.7f1 LTS).
5.	Navigate to File > Open Project and select the folder where you extracted the game's source code.
6.	Connect your Android device to your computer.
7.	In Unity Editor, navigate to Build Settings (File > Build Settings).
8.	Select Android as the target platform and click on "Switch Platform."
9.	Click on "Build and Run" to deploy the game to your Android device.
## Game Controls:
-	Accelerate/Boost: Touch and move upwards on the screen
-	Brake/Reverse: Touch and move downwards on the screen
-	Steer Left: Touch and move leftwards on the screen
-	Steer Right: Touch and move rightwards on the screen
-	Pause Menu: Tap on the screen to pause the game
## Gameplay:
-	Tap and hold on the screen to accelerate and boost your car's speed.
-	Swipe downwards on the screen to brake or reverse your car.
-	Swipe left or right on the screen to steer your car in the corresponding direction.
-	Collect coins and power-ups to enhance your performance and score.
-	Avoid obstacles and other cars on the track to maintain your speed and avoid crashes.
-	Complete each level as quickly as possible to unlock new tracks and cars.
## Customization:
-	Explore the Unity Editor to customize various aspects of the game, including track layouts, car models, and environmental settings.
-	Modify scripts and assets in Visual Studio Code to add new features, tweak gameplay mechanics, or improve performance.
Troubleshooting:
-	If you encounter any issues while running the game on your Android device, ensure that your device meets the system requirements, and that Unity is properly configured for Android deployment.
-	Refer to the troubleshooting section in the GitHub repository or reach out to the game's developer for assistance.
